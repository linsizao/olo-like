# olo-like

基于 Cocos Creator 3.8.6 的竖屏微信小游戏。两个人共用一台设备，把圆片滑进对面的同色区，也可以撞走对方已经得分的圆片。不需要账号、服务器或联网。当前版本聚焦 OLO 红蓝双人棋盘，是非官方原型，不含原版音效或在线模式。

| 想做什么                 | 入口                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 马上试玩                 | 用浏览器打开 [offline.html](offline.html)，鼠标和触屏都可以玩                       |
| 在微信中调试             | 微信开发者工具导入 [wechat/](wechat/)，类型选「小游戏」，不要导入仓库根目录         |
| 修改游戏                 | Cocos Creator **3.8.6** 打开仓库根目录，双击 [Game.scene](assets/Game.scene) 并预览 |
| 了解代码、重新打包或验收 | 阅读[开发指南](docs/development.md)                                                 |
| 查看竖屏效果             | [手机尺寸截图](previews/phone.png)                                                  |

**玩法。** 蓝方从下往上，红方从上往下。按住白区中带光圈的圆片，可横移选起点，再向对面滑出。出手速度取决于松手前的动作，不是拖动的总距离。进入同色区会出现白环，全部静止后更新比分；撞出色区就失分。滑过头进入对方白区，会把圆片送入对方队列。双方库存都用完才结算，再来一局交换先手。点上方右角或下方左角的小圆点可查看规则。
