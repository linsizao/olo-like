# olo-like

基于 Cocos Creator 3.8.6 的竖屏微信小游戏。两个人共用一台设备，把圆片滑进对面的同色区，也可以撞走对方已经得分的圆片。不需要账号、服务器或联网。当前版本聚焦 OLO 同屏双人棋盘，是非官方原型，不含原版音效或在线模式。

**开始对局。** 两人坐在设备两端，点「双人」即可开局。每次开局从红、蓝、黄、绿中随机分配两种不同颜色，首局由下方先手。语言、音量和战绩保存在当前设备。

**玩法。** 下方玩家向上发射，上方玩家向下发射。点发射区一角的小圆点可以换球。按住待发球可以在己方白区内摆位。向前直推或斜推，球的前缘到达白区边线时就会出手，快推可以打出强球。也可以在白区内提前松手，按最后一段前推的方向和距离发射。遇到已有球挡路时，待发球会在接触点出手。只横移后松手不会耗球。球在白区内也能撞球、撞边或弹回彩色区。

**回合结算。** 等最后一枚球停稳，再按各球圆心的最终位置结算。只有本次发射始终没离开己方白区、也没撞球或撞边的球才会碎裂。其余球停在己方白区会回收，停在对方白区会被夺取，复用次数不限。白环表示球在得分区内，全场停稳后更新比分。

**暂停与继续。** 从两块颜色交界的中线向自己拉开，松手暂停。短拉松手会自动合拢。暂停后点「继续」接着玩，点「菜单」结束本组对局。手机系统返回由微信处理，如果因此切到后台，再打开时会停在暂停页。

**连续对局。** 结算时，各自面前的大数字是本局得分，角落的小数字是本次连续对局的累计胜局。赢一局加一，平局双方都不加。点「继续」沿用双方颜色并交换先手。点「菜单」结束这一组，下次从 0:0 开始。菜单里的「记录」保留本机所有已完成局的战绩。
