# olo-like

基于 Cocos Creator 3.8.6 的竖屏微信小游戏。两个人共用一台设备，把圆片滑进对面的同色区，也可以撞走对方已经得分的圆片。不需要账号、服务器或联网。当前版本聚焦 OLO 红蓝双人棋盘，是非官方原型，不含原版音效或在线模式。

| 想做什么                 | 入口                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 马上试玩                 | 用浏览器打开 [offline.html](offline.html)，鼠标和触屏都可以玩                       |
| 在微信中调试             | 微信开发者工具导入 [wechat/](wechat/)，类型选「小游戏」，不要导入仓库根目录         |
| 修改游戏                 | Cocos Creator **3.8.6** 打开仓库根目录，双击 [Game.scene](assets/Game.scene) 并预览 |
| 了解代码、重新打包或验收 | 阅读[开发指南](docs/development.md)                                                 |

**开始对局。** 两人坐在设备两端，点「双人」即可开局。蓝方先手。语言、音量和战绩保存在当前设备。

**玩法。** 蓝方从下往上，红方从上往下。点发射区一角的小圆点可以换球。按住待发球，在白区内拖到想要的出手位置，保持按住，再向前直推或斜推并松手。球从松手时显示的位置飞出，最后一段推得越远，球速越快。只横移后松手不会耗球。球在白区内也能撞球、撞边或弹回彩色区。

**回合结算。** 等最后一枚球停稳，再按各球圆心的最终位置结算。进过彩色区的球停在己方白区会回收，停在对方白区会被夺取。已复用三次的球若最终留在任一白区，就会被骨指淘汰。本次发射始终没出己方白区的球会原地碎裂。白环表示球在得分区内，全场停稳后更新比分。

**暂停与继续。** 对局中从屏幕任一侧边缘向内滑，或使用浏览器返回、键盘 Esc，可以暂停。两半棋盘分开后，点「继续」合上棋盘，从原位置接着玩。切后台也会暂停。

**连续对局。** 结算时，各自面前的大数字是本局得分，角落的小数字是本次连续对局的累计胜局。赢一局加一，平局双方都不加。点「继续」交换先手并开始下一局。点「菜单」结束这一组，下次从 0:0 开始。菜单里的「记录」保留本机所有已完成局的战绩。
