# 第一章：产品概述

## 1.1 产品介绍

OLO 是一款以圆形棋子弹射为核心玩法的物理策略游戏。

玩家通过手指拖动圆片，控制弹射方向和力度，将己方圆片送入目标计分区域，同时利用圆片之间的物理碰撞，改变对手圆片的位置，争取更多有效得分。

游戏融合了桌面冰壶、沙狐球和台球的部分玩法特点。

游戏操作简单，但需要考虑：

- 弹射方向。
- 弹射力度。
- 圆片的大小与重量。
- 圆片之间的碰撞。
- 目标区域的位置。
- 对手圆片的分布。
- 圆片是否会被对方夺取。
- 圆片是否能够回收并再次使用。

本项目第一阶段将原版 OLO 的双人对抗玩法改造成单人对战 AI 的游戏体验。

## 1.2 产品目标

1. 保留 OLO 原版的核心物理弹射玩法。
2. 保留不同尺寸、重量圆片之间的物理差异。
3. 保留碰撞、得分、回收、夺取和特殊淘汰机制。
4. 增加单机 AI 对手，让玩家随时可以开始游戏。
5. 通过不同 AI 难度增加游戏挑战。
6. 通过新手引导降低游戏理解成本。
7. 提供完整的开始游戏、游戏中、暂停、结算、重新开始流程。

## 1.4 核心用户体验

游戏需要围绕以下体验展开：

**第一：操作简单。**

玩家只需要选择圆片，拖动并释放，就可以完成一次弹射。

**第二：物理反馈真实。**

不同大小、重量的圆片具有不同的运动表现。圆片相互碰撞时，需要有明显的力量反馈。

**第三：策略空间充足。**

玩家不仅可以追求自己的得分，还可以主动撞击 AI 的圆片，改变对方的得分情况。

**第四：对局节奏轻松。**

不需要复杂的操作教学，不强制使用倒计时，玩家可以按照自己的节奏完成每一次操作。

# 第二章：核心游戏规则

## 2.1 游戏基本设定

游戏采用一块双端对抗式棋盘。

棋盘分为玩家区域、AI 区域、中间碰撞区域以及双方的目标计分区域。

玩家控制一种颜色的 OLO 圆片，AI 控制另一种颜色的 OLO 圆片。

双方轮流进行弹射。

每一方初始拥有 6 枚 OLO 圆片。

每一方的圆片包含三种不同尺寸：

- 小型圆片。
- 中型圆片。
- 大型圆片。

大型圆片更重，撞击能力更强；小型圆片相对轻巧，更容易通过较小的力度进行精细控制。

具体尺寸分配暂定为每种 2 枚，后续可以根据原版视频画面进一步校准。

## 2.2 圆片基本规则

每一枚圆片具有以下属性：

| 属性       | 说明                                         |
| ---------- | -------------------------------------------- |
| 所属阵营   | 玩家或 AI                                    |
| 尺寸       | 小、中、大                                   |
| 重量       | 不同尺寸具有不同重量                         |
| 当前位置   | 当前棋盘坐标                                 |
| 当前状态   | 待使用、运动中、计分、可回收、被夺取、已淘汰 |
| 回收次数   | 记录被回收并重新使用的次数                   |
| 是否可操作 | 判断当前玩家能否选择该圆片                   |

## 2.3 弹射规则

1. 玩家只能选择当前属于自己控制范围的可操作圆片。
2. 点击圆片后进入选中状态。
3. 按住圆片向目标方向拖动。
4. 拖动方向决定圆片的发射方向。
5. 拖动距离决定弹射力度。
6. 松开手指后，圆片开始运动。
7. 圆片与其他圆片发生碰撞时，按照物理效果改变运动方向和速度。
8. 所有圆片停止运动后，本次操作结束。
9. 系统更新计分情况，并切换到下一方操作。

玩家每次只能发射一枚圆片。

## 2.4 得分规则

玩家需要尽可能将自己的 OLO 圆片送入对应颜色的目标区域。

基础计分规则：

- 每枚有效停留在己方目标区域的圆片获得 1 分。
- 圆片进入目标区域后立即产生得分反馈。
- 圆片被其他圆片撞出目标区域后，取消对应得分。
- 同一枚圆片不能重复计算得分。
- 最终按照对局结束时双方有效计分圆片数量进行结算。

得分显示需要实时更新。

## 2.5 圆片碰撞规则

圆片之间允许发生碰撞。

碰撞结果由圆片大小、重量、速度、碰撞角度决定。

主要碰撞情况：

**情况一：正面碰撞**

一枚圆片正面撞击另一枚圆片，被撞击的圆片向前移动。

**情况二：侧面碰撞**

圆片从侧面撞击另一枚圆片，改变对方的运动方向。

**情况三：连续碰撞**

一枚圆片撞击第一枚圆片后，第一枚圆片继续撞击其他圆片。

**情况四：撞出计分区域**

玩家可以将 AI 的圆片撞出 AI 的计分区域，从而降低 AI 得分。

**情况五：利用碰撞调整位置**

玩家可以通过轻微撞击，让自己的圆片进入更有利的位置。

## 2.6 圆片回收规则

当一枚圆片被撞回所属玩家的回收区域时，可以重新使用。

回收规则：

1. 圆片进入所属阵营的回收区域。
2. 系统判断圆片是否满足回收条件。
3. 满足条件后，该圆片恢复为可操作状态。
4. 玩家可以再次选择并发射。
5. 每次回收并重新使用，回收次数增加一次。
6. 单枚圆片最多复用三次。
7. 达到三次使用限制后，触发 Death Finger 特殊淘汰机制。

界面需要显示圆片的回收状态。

## 2.7 圆片夺取规则

当圆片过度弹射，进入对方可以控制的区域时，可能被对方夺取。

夺取后的处理：

- 圆片转为对方可操作状态。
- 原有圆片视觉颜色可以保留，以便识别来源。
- 原所属方不再能够直接操作该圆片。
- 对方可以在自己的回合中使用被夺取的圆片。

具体夺取区域以原版棋盘布局为准。

## 2.8 Death Finger 特殊机制

Death Finger 是 OLO 的特殊淘汰机制。

当一枚 OLO 达到三次回收复用限制后，触发死亡淘汰。

表现流程：

1. 圆片进入触发区域。
2. 游戏检测回收次数。
3. 触发 Death Finger 动画。
4. 骷髅手指从画面边缘出现。
5. 手指触碰圆片。
6. 圆片被移除。
7. 该圆片不再参与本局游戏。

动画不应过长，不能影响整体游戏节奏。

## 2.9 游戏结束规则

采用双方可操作 OLO 全部耗尽的结束判定。

当双方都没有可继续使用的圆片，且棋盘上所有圆片停止运动后，游戏结束。

最终根据双方目标计分区域内有效圆片数量计算成绩。

- 玩家得分高于 AI：玩家获胜。
- 玩家得分低于 AI：玩家失败。
- 双方得分相同：平局。

## P03：AI 难度选择

### 页面目的

让玩家选择本局 AI 对手的难度。

### 页面布局

```text
┌──────────────────────────────┐
│          选择对手              │
│                              │
│        [AI 对手形象]           │
│                              │
│      ○ 简单                   │
│      ○ 普通                   │
│      ○ 困难                   │
│                              │
│       [开始对局]              │
│                              │
│          返回                 │
└──────────────────────────────┘
```

### 难度设置

**简单 Easy**

- AI 优先尝试将圆片送入目标区域。
- 弹射力度控制较为保守。
- 碰撞策略简单。
- 偶尔出现不够精准的操作。
- 适合第一次接触游戏的玩家。

**普通 Normal**

- AI 能够判断目标区域。
- 能够进行基本碰撞。
- 能够主动攻击玩家的计分圆片。
- 能够根据棋盘情况调整弹射力度。

**困难 Hard**

- AI 能够综合分析棋盘局势。
- 优先选择得分收益较高的操作。
- 主动将玩家圆片撞出目标区域。
- 能够利用大型圆片进行强力碰撞。
- 能够选择更复杂的弹射路线。

### 页面交互

1. 默认选中普通难度。
2. 点击其他难度切换选择状态。
3. 点击开始对局。
4. 根据难度创建本局 AI 对手。
5. 进入对局准备界面。

难度选择仅影响 AI 的决策能力，不允许 AI 违反物理规则。

## P04：新手教学

### 页面目的

通过实际操作让玩家理解游戏。

教学采用逐步引导方式，不使用大段文字说明。

### 教学第一步：认识棋盘

画面展示完整游戏棋盘。

提示：

「将你的 OLO 圆片弹射到目标区域，尽可能获得更多分数。」

玩家点击继续。

### 教学第二步：选择圆片

画面突出显示一枚己方圆片。

提示：

「点击并按住你的圆片。」

交互：

- 玩家需要点击指定圆片。
- 圆片出现高亮边框。
- 其他圆片降低视觉强调程度。

完成后进入下一步。

### 教学第三步：控制方向

提示：

「向你希望圆片移动的方向拖动。」

交互：

- 玩家拖动圆片。
- 显示方向指示线。
- 指示线随拖动方向改变。

### 教学第四步：控制力度

提示：

「拖动距离越远，弹射力度越大。」

交互：

- 拖动距离变化。
- 力度提示同步变化。
- 展示弱、中、强三个力度区间。

### 教学第五步：释放圆片

提示：

「松开手指，发射你的 OLO！」

交互：

- 玩家松开手指。
- 圆片开始运动。
- 其他圆片产生真实碰撞反馈。

### 教学第六步：理解计分

提示：

「让你的圆片停留在对应颜色的目标区域，获得分数。」

交互：

- 圆片进入目标区域。
- 目标区域产生颜色反馈。
- 分数增加 1 分。

### 教学第七步：碰撞与策略

提示：

「不仅可以得分，还可以撞开对手的圆片。」

交互：

- 演示玩家圆片撞击 AI 圆片。
- AI 圆片被撞出目标区域。
- AI 分数减少。

### 教学第八步：回收与 Death Finger

提示：

「被弹回的圆片可以重新使用，但复用次数有限。」

交互：

- 演示圆片进入回收区域。
- 显示回收次数。
- 演示达到三次复用限制后的 Death Finger 动画。

### 教学完成

展示：

「你已经掌握 OLO 的基本玩法！」

按钮：

- 开始游戏。
- 再看一次教学。

教学完成后记录本地状态，后续进入游戏不再自动播放。

显示 AI 剩余圆片。

每枚圆片对应一个状态标识：

- 正常：正常颜色。
- 已发射：变暗。
- 可回收：显示回收标记。
- 已淘汰：显示灰色或空位。
- 被玩家夺取：显示控制权变化标记。

**C. 游戏棋盘区域**

棋盘是主要交互区域。

需要展示：

- 双方起始区域。
- 双方目标计分区域。
- 中间碰撞区域。
- 玩家圆片。
- AI 圆片。
- 当前被选中的圆片。
- 弹射方向指示线。
- 目标区域状态。

**D. 玩家信息区域**

展示：

- 玩家当前分数。
- 玩家剩余圆片。
- 玩家回合状态。
- 暂停按钮。

### 6.3 玩家回合交互

玩家回合开始后：

1. 玩家回合提示出现。
2. 当前可操作圆片产生轻微高亮。
3. 玩家选择一枚圆片。
4. 圆片进入选中状态。
5. 玩家拖动圆片。
6. 系统显示方向和力度提示。
7. 玩家松开手指。
8. 圆片开始运动。
9. 游戏进入物理结算状态。
10. 所有圆片停止运动。
11. 更新双方分数和圆片状态。
12. 切换到 AI 回合。

### 6.4 圆片选择交互

点击可操作圆片时：

- 圆片出现选中描边。
- 圆片轻微放大。
- 显示可拖动反馈。
- 显示该圆片的尺寸差异。

如果点击的是不可操作圆片：

- 不执行弹射。
- 不切换回合。
- 可以显示简短的不可操作提示。

### 6.5 圆片拖动交互

玩家按住圆片并开始拖动：

- 圆片跟随手指。
- 根据拖动方向显示弹射方向。
- 根据拖动距离显示力度。
- 方向指示线实时变化。
- 力度提示同步变化。

拖动距离分为：

- 轻力度。
- 中力度。
- 强力度。

力度达到最大限制后，不再继续增加。

如果玩家拖动距离低于最小发射阈值：

- 不执行弹射。
- 圆片回到原位置。
- 当前回合不消耗。

### 6.6 圆片释放交互

松开手指后：

- 圆片脱离手指。
- 按当前方向和力度进行弹射。
- 圆片产生移动动画。
- 其他圆片受到碰撞影响。
- 棋盘进入运动状态。

在所有圆片停止前：

- 玩家不能选择其他圆片。
- 玩家不能再次弹射。
- 不允许切换回合。
- 暂停功能仍然有效。

### 6.7 AI 回合交互

玩家完成弹射并结算后，自动进入 AI 回合。

AI 回合流程：

1. AI 回合提示出现。
2. AI 分析当前棋盘。
3. AI 选择一枚可操作圆片。
4. 显示短暂思考动画。
5. AI 确定弹射方向。
6. AI 确定弹射力度。
7. AI 执行弹射。
8. 圆片发生运动和碰撞。
9. 棋盘停止运动。
10. 更新双方得分。
11. 切换回玩家回合。

AI 思考时间应保持适中，不宜让玩家长时间等待。

### 6.8 分数更新交互

当圆片进入有效计分区域：

- 目标区域出现短暂高亮。
- 分数数字增加。
- 显示得分动画。
- 圆片保留在棋盘上。

当圆片被撞出计分区域：

- 目标区域高亮消失。
- 分数减少。
- 显示失分反馈。

分数更新必须在所有碰撞停止后进行统一结算，避免运动过程中出现分数反复跳动。

### 6.9 圆片状态反馈

圆片至少包含以下状态：

| 状态   | 视觉表现           | 是否可操作     |
| ------ | ------------------ | -------------- |
| 待使用 | 正常显示           | 是             |
| 已选中 | 高亮描边           | 是             |
| 瞄准中 | 显示方向线         | 是             |
| 运动中 | 正常运动           | 否             |
| 停止中 | 轻微缓动           | 否             |
| 计分中 | 目标区域反馈       | 否             |
| 可回收 | 回收标识           | 是             |
| 被夺取 | 所属控制方标识变化 | 由新控制方操作 |
| 已淘汰 | 消失或变为灰色     | 否             |

# 第五章：AI 对手行为设计

## 5.1 AI 设计目标

AI 需要模拟真实玩家的操作。

不能直接修改棋盘状态，也不能直接决定圆片最终位置。

AI 必须和玩家遵循相同的物理规则。

AI 的主要任务：

- 选择合适的圆片。
- 判断弹射方向。
- 判断弹射力度。
- 寻找可得分机会。
- 判断是否需要撞击对方圆片。
- 避免自己的圆片被撞出计分区域。

## 5.2 AI 决策优先级

建议按照以下顺序判断：

1. 是否存在直接得分机会。
2. 是否可以将对方得分圆片撞出区域。
3. 是否可以将己方圆片送入目标区域。
4. 是否可以通过碰撞调整己方圆片位置。
5. 是否需要避免圆片过度弹射。
6. 是否需要保留大型圆片用于关键碰撞。

## 5.3 AI 难度差异

| 难度 | AI 特征                            |
| ---- | ---------------------------------- |
| 简单 | 以直接得分为主，力度控制一般       |
| 普通 | 会根据圆片位置进行碰撞和得分判断   |
| 困难 | 能够综合考虑碰撞、得分、回收和防守 |

## 5.4 AI 行为表现

AI 不能每次都立即发射。

需要有适度的思考表现：

- 选中圆片。
- 短暂停顿。
- 显示方向提示。
- 执行弹射。

简单难度可以更快完成思考。

困难难度可以稍微延长思考时间。

# 第六章：游戏状态与特殊情况

## 6.1 游戏状态

整个游戏主要包含：

1. 等待开始。
2. 玩家回合。
3. 玩家选择圆片。
4. 玩家瞄准。
5. 玩家弹射。
6. 物理运动。
7. 碰撞结算。
8. 得分结算。
9. AI 回合。
10. AI 思考。
11. AI 弹射。
12. 暂停。
13. 游戏结束。

状态变化：

等待开始 → 玩家回合 → 玩家瞄准 → 弹射 → 物理结算 → AI 回合 → AI 思考 → AI 弹射 → 物理结算 → 玩家回合。

如果触发结束条件，则进入结算状态。

## 6.2 异常和边界情况

**情况一：玩家点击空白区域**

不产生任何操作。

**情况二：玩家选择 AI 圆片**

不允许操作。

**情况三：玩家选择不可操作圆片**

显示不可操作状态，不消耗回合。

**情况四：玩家拖动后取消**

圆片返回原位置，不消耗回合。

**情况五：玩家拖动到最大力度**

力度达到上限后保持不变。

**情况六：圆片撞击棋盘边界**

按照边界碰撞规则反弹或停留，不允许无故消失。

**情况七：多个圆片连续碰撞**

等待所有圆片停止后统一结算。

**情况八：圆片进入回收区域**

更新回收次数和可操作状态。

**情况九：圆片达到淘汰次数**

触发 Death Finger 并移除圆片。

**情况十：当前玩家没有可操作圆片**

自动跳过当前玩家回合。

**情况十一：双方都没有可操作圆片**

等待场上所有运动结束，进入游戏结算。

**情况十二：游戏过程中切换后台**

暂停游戏，恢复前保持原有棋盘状态。

**情况十三：玩家在 AI 思考时暂停**

停止 AI 操作，恢复游戏后继续 AI 回合。

# 第七章：视觉与交互设计规范

## 7.1 整体视觉风格

采用极简、干净、现代的视觉设计。

核心视觉元素：

- 纯色游戏棋盘。
- 高对比度圆片。
- 简洁的目标区域。
- 少量辅助文字。
- 清晰的分数显示。
- 柔和的动画反馈。

避免：

- 过多复杂装饰。
- 过度拟物化。
- 过多 UI 面板。
- 大量文字说明。
- 复杂的游戏 HUD。

## 7.2 圆片视觉

不同阵营通过颜色区分。

不同尺寸通过直径区分。

不同重量通过运动表现区分，而不是仅依赖外观。

圆片应具有：

- 清晰的边缘。
- 轻微的立体感。
- 柔和阴影。
- 碰撞时的视觉反馈。
- 运动时的速度感。

## 7.3 动画规范

**圆片选中**

轻微放大并显示描边。

**圆片拖动**

跟随手指移动，显示方向线。

**圆片弹射**

快速脱离当前位置，进入运动状态。

**圆片碰撞**

出现轻微震动或碰撞反馈。

**圆片得分**

目标区域短暂高亮，分数跳动。

**圆片回收**

显示简洁的回收提示。

**Death Finger**

手指出现、触碰圆片、圆片消失。

**游戏胜利**

展示简洁的胜利动画。

所有动画都不能长时间阻塞玩家下一次操作。

## 7.4 声音设计

建议包含：

- 圆片选中音效。
- 圆片弹射音效。
- 圆片碰撞音效。
- 圆片进入目标区域音效。
- 得分音效。
- 回收音效。
- Death Finger 音效。
- 胜利音效。
- 失败音效。

背景音乐采用轻松、舒缓的风格。

所有声音均可单独关闭。

# 第十章：验收标准

## 10.1 主菜单验收

- 能够正常进入游戏。
- 能够进入新手教学。
- 能够查看规则。
- 能够进入设置。
- 页面切换正常。

## 10.2 弹射操作验收

- 能够选中己方可操作圆片。
- 能够拖动圆片。
- 拖动方向能够影响运动方向。
- 拖动距离能够影响运动力度。
- 松开后能够正确发射。
- 取消拖动不会消耗回合。
- 弹射后不能立即进行第二次操作。

## 10.3 物理碰撞验收

- 圆片之间能够发生碰撞。
- 不同大小的圆片表现不同。
- 大型圆片具有更强的撞击能力。
- 碰撞方向合理。
- 多枚圆片连续碰撞正常。
- 圆片不会无故穿透棋盘边界。

## 10.4 得分验收

- 圆片进入有效目标区域能够得分。
- 圆片被撞出区域能够取消得分。
- 同一圆片不能重复计分。
- 双方分数正确显示。
- 最终得分与棋盘状态一致。

## 10.5 AI 验收

- AI 能够正常完成回合。
- AI 不会操作玩家圆片。
- AI 不能违反物理规则。
- 三种难度具有明显区别。
- AI 不会出现无限思考。
- AI 操作结束后能够正常切换回玩家回合。

## 10.6 特殊规则验收

- 圆片回收正常。
- 回收次数正确记录。
- 圆片达到限制后触发 Death Finger。
- 圆片被夺取后控制权正确变化。
- 圆片淘汰后不再参与后续游戏。
- 双方没有可操作圆片时能够正常结束。

## 10.7 游戏流程验收

- 能够正常开始对局。
- 能够正常暂停。
- 能够正常继续。
- 能够重新开始。
- 能够放弃当前对局。
- 能够正常结算。
- 能够再次开始新对局。
- 游戏切换后台后能够恢复。

3. 选择 AI 难度。
4. 首次进入完成新手教学。
5. 进入游戏棋盘。
6. 选择自己的圆片。
7. 拖动圆片控制方向和力度。
8. 释放圆片进行弹射。
9. 观察圆片碰撞和得分。
10. 等待 AI 完成操作。

**第一阶段的核心验收目标：**

不需要网络、不需要其他玩家，仅靠一个人和 AI，就能够完整体验 OLO 从开始、操作、对抗到结束的整个游戏过程。

# 第十二章：游戏音效系统设计（Audio Design）

## 12.1 音效设计目标

OLO 的音效不仅用于反馈玩家操作，还需要增强圆片弹射、物理碰撞和得分过程中的真实感。

音效设计遵循以下原则：

1. 操作有反馈：玩家每一次有效操作都应有明确的声音反馈。
2. 碰撞有层次：不同力度、不同情况的碰撞应具有不同的声音表现。
3. 得分有反馈：进入目标区域、成功得分和失去分数需要使用不同音效。
4. 特殊事件有辨识度：圆片回收、夺取、Death Finger 等机制需要独立音效。
5. 声音不过度干扰：避免频繁播放重复音效，保持整体听感舒适。
6. 游戏状态与声音同步：暂停、继续、结束和切换页面时，音频需要正确切换。

整体声音风格：

- 简洁。
- 清脆。
- 轻松。
- 具有一定的物理质感。
- 不使用过于夸张的电子游戏音效。
- 不使用人声旁白。

## 12.2 音频分类

游戏声音分为三大类：

### A. 背景音乐 BGM

用于营造游戏氛围。

包含：

| 音效编号 | 名称           | 使用场景     |
| -------- | -------------- | ------------ |
| BGM001   | 主菜单背景音乐 | 主菜单页面   |
| BGM002   | 游戏背景音乐   | 正式对局     |
| BGM003   | 结算背景音乐   | 游戏结束页面 |

背景音乐要求：

**主菜单音乐**

- 轻松、简洁。
- 节奏舒缓。
- 能够体现休闲策略游戏的特点。
- 循环播放。

**游戏音乐**

- 比主菜单音乐稍有节奏感。
- 不影响玩家思考。
- 不过度紧张。
- 玩家和 AI 对战期间持续播放。

**结算音乐**

- 胜利、失败、平局分别使用不同的音乐片段。
- 音乐长度适中。
- 不应循环播放过长的结果提示。

### B. 操作音效 SFX

用于反馈玩家和 AI 的操作。

| 音效编号 | 名称              | 触发场景                   |
| -------- | ----------------- | -------------------------- |
| SFX001   | 按钮点击          | 点击 UI 按钮               |
| SFX002   | 页面切换          | 页面切换                   |
| SFX003   | 圆片选中          | 选中圆片                   |
| SFX004   | 圆片拖动          | 拖动圆片时的可选轻微摩擦声 |
| SFX005   | 弹射释放          | 玩家或 AI 释放圆片         |
| SFX006   | 轻微碰撞          | 圆片发生轻微碰撞           |
| SFX007   | 中等碰撞          | 圆片发生中等力度碰撞       |
| SFX008   | 强烈碰撞          | 圆片发生强烈碰撞           |
| SFX009   | 边界碰撞          | 圆片碰撞棋盘边缘           |
| SFX010   | 目标区域进入      | 圆片进入有效目标区域       |
| SFX011   | 得分确认          | 圆片最终停留并成功得分     |
| SFX012   | 失分              | 圆片被撞出目标区域         |
| SFX013   | 回收提示          | 圆片进入回收区域           |
| SFX014   | 回收完成          | 圆片恢复可使用状态         |
| SFX015   | 圆片夺取          | 圆片控制权发生转移         |
| SFX016   | Death Finger 出现 | 特殊淘汰动画开始           |
| SFX017   | Death Finger 触碰 | 手指触碰圆片               |
| SFX018   | 圆片淘汰          | 圆片被移除                 |
| SFX019   | 回合切换          | 玩家和 AI 之间切换回合     |
| SFX020   | AI 思考提示       | AI 开始思考，可选          |
| SFX021   | 游戏胜利          | 玩家获得胜利               |
| SFX022   | 游戏失败          | 玩家失败                   |
| SFX023   | 游戏平局          | 双方得分相同               |
| SFX024   | 暂停              | 游戏暂停                   |
| SFX025   | 继续游戏          | 游戏恢复                   |
| SFX026   | 确认操作          | 确认重新开始或退出         |
| SFX027   | 错误操作提示      | 点击不可操作圆片等情况     |

### C. 特殊氛围音效

用于增强重要事件的表现。

例如：

- 游戏开始时的轻微氛围音。
- 连续碰撞时的声音层次。
- Death Finger 出现时的特殊声音。
- 游戏胜利时的庆祝声音。
- 游戏结束时的收尾声音。

特殊音效需要与普通操作音效区分开，避免声音过于单调。

## 12.3 圆片操作音效逻辑

### 12.3.1 选中圆片

触发条件：

玩家点击一枚可以操作的圆片。

音效：

SFX003 圆片选中音效。

声音表现：

- 短促。
- 清脆。
- 轻微的确认感。

播放时机：

圆片进入选中状态后立即播放。

以下情况不播放：

- 点击空白区域。
- 点击 AI 的圆片。
- 点击已经淘汰的圆片。

### 12.3.2 拖动圆片

触发条件：

玩家按住圆片并拖动。

声音表现：

可以使用非常轻微的摩擦声，但建议首版默认不播放持续拖动声音。

原因：

拖动过程中可能持续数秒，如果一直播放声音，会影响整体体验。

拖动过程中只通过视觉表现反馈：

- 圆片跟随手指。
- 显示弹射方向。
- 显示弹射力度。

### 12.3.3 释放圆片

触发条件：

玩家松开手指，成功执行弹射。

音效：

SFX005 弹射释放音效。

声音表现：

- 短促的弹射声。
- 根据弹射力度改变音效强度。
- 弹射力度越大，声音可以稍微更明显。

注意：

取消拖动、拖动距离不足时，不播放弹射音效。

AI 弹射也使用相同音效，确保双方操作体验一致。

---

## 12.4 物理碰撞音效逻辑

这是整个音效系统中最重要的部分。

### 12.4.1 碰撞触发条件

当两枚圆片发生有效物理碰撞时，触发碰撞音效。

根据碰撞力度分为三种：

**轻微碰撞**

触发 SFX006。

表现：

- 声音较轻。
- 短促。
- 适合圆片轻微接触。

**中等碰撞**

触发 SFX007。

表现：

- 声音清晰。
- 有明显的接触感。
- 适合正常力度撞击。

**强烈碰撞**

触发 SFX008。

表现：

- 声音更厚重。
- 有明显冲击感。
- 适合大型圆片之间的强烈碰撞。

### 12.4.2 碰撞力度与音量

碰撞音效根据实际碰撞强度动态调整音量。

建议划分：

| 碰撞等级 | 声音表现       |
| -------- | -------------- |
| 轻微     | 低音量、轻脆   |
| 中等     | 中等音量、清晰 |
| 强烈     | 较高音量、厚重 |

具体音量根据实际游戏测试调整。

不允许因为连续碰撞而导致音量不断叠加，超过正常听觉范围。

### 12.4.3 连续碰撞

例如：

玩家发射一枚大型圆片，连续撞击三枚其他圆片。

声音播放逻辑：

1. 第一次碰撞播放对应音效。
2. 第二次碰撞根据碰撞力度播放对应音效。
3. 第三次碰撞继续根据力度播放。
4. 短时间内如果发生大量碰撞，优先播放最明显的碰撞声音。
5. 避免多个音效完全重叠。

连续碰撞可以使用不同音色的音效变体，减少重复感。

### 12.4.4 棋盘边界碰撞

触发条件：

圆片撞击棋盘边缘。

音效：

SFX009 边界碰撞。

要求：

- 与圆片之间的碰撞音效有所区别。
- 根据撞击力度改变音量。
- 不应每次轻微接触边界都产生明显声音。

---

## 12.5 得分音效逻辑

### 12.5.1 圆片进入目标区域

触发条件：

圆片进入己方有效计分区域。

音效：

SFX010 目标区域进入。

声音表现：

- 轻快。
- 清晰。
- 表示圆片已经进入目标区域。

注意：

进入目标区域不代表最终得分已经确定。

### 12.5.2 成功得分

触发条件：

圆片完全停止运动，经过最终位置判定后，仍然处于有效计分区域。

音效：

SFX011 得分确认。

声音表现：

- 比进入目标区域时更加明确。
- 可以搭配轻微的得分提示音。
- 分数数字同步跳动。

触发顺序：

1. 圆片停止。
2. 系统判断有效计分状态。
3. 确认获得分数。
4. 播放得分音效。
5. 更新分数显示。

### 12.5.3 失去分数

触发条件：

已经计分的圆片被撞出目标区域。

音效：

SFX012 失分。

声音表现：

- 短促。
- 略带下降感。
- 不需要过度惩罚性声音。

触发顺序：

1. 圆片被撞出目标区域。
2. 圆片停止运动。
3. 系统确认不再满足计分条件。
4. 播放失分音效。
5. 更新双方分数。

### 12.5.4 得分与失分同时发生

如果一次碰撞同时导致：

- 玩家获得 1 分。
- AI 失去 1 分。

声音处理：

优先播放主要得分音效。

失分反馈可以采用较轻的辅助音效，避免两个声音同时过于突出。

---

## 12.6 圆片回收音效逻辑

### 12.6.1 进入回收区域

触发条件：

圆片进入所属阵营的有效回收区域。

音效：

SFX013 回收提示。

声音表现：

- 轻微的确认音。
- 提醒玩家该圆片已经进入回收区域。

### 12.6.2 回收完成

触发条件：

圆片满足回收条件，恢复为可使用状态。

音效：

SFX014 回收完成。

声音表现：

- 与普通得分音效有所区别。
- 表现出圆片重新获得使用机会。

同时更新：

- 圆片可操作状态。
- 圆片回收次数。
- 圆片剩余使用状态。

注意：

只有正式完成回收后才播放回收完成音效。

### 12.6.3 圆片达到使用限制

触发条件：

圆片达到三次复用限制，并进入 Death Finger 触发流程。

不再播放普通回收完成音效。

改为播放 Death Finger 专属音效。

---

## 12.7 圆片夺取音效逻辑

触发条件：

圆片进入对方控制区域，并正式完成控制权转移。

音效：

SFX015 圆片夺取。

声音表现：

- 简短的提示音。
- 与普通得分音效区分。
- 提醒玩家圆片控制权发生变化。

声音触发时机：

必须在控制权正式转移后播放，不能在圆片刚进入区域时就播放。

---

## 12.8 Death Finger 音效逻辑

Death Finger 是游戏中特殊性较强的事件，需要设计独立的声音流程。

音效分为三个阶段。

### 第一阶段：Death Finger 出现

触发条件：

圆片达到淘汰条件，触发特殊动画。

播放：

SFX016 Death Finger 出现。

声音表现：

- 带有轻微悬念感。
- 与普通操作音效明显区分。
- 不需要恐怖或过于夸张。

### 第二阶段：手指触碰圆片

触发条件：

Death Finger 动画中的手指接触圆片。

播放：

SFX017 Death Finger 触碰。

声音表现：

- 轻微触碰声。
- 可以加入一点特殊的音效质感。

### 第三阶段：圆片淘汰

触发条件：

圆片正式消失。

播放：

SFX018 圆片淘汰。

声音表现：

- 短促的消失音。
- 表示该圆片不再参与本局游戏。

整个流程必须与画面动画同步。

## 12.9 玩家和 AI 回合音效

### 玩家回合开始

触发条件：

AI 操作结束，轮到玩家操作。

播放：

SFX019 回合切换。

可以同时显示：

「你的回合」

不建议每次都使用过于明显的提示声音，以免长期游戏造成干扰。

### AI 回合开始

触发条件：

玩家操作结束，轮到 AI。

播放：

SFX019 回合切换。

同时显示：

「AI 的回合」

### AI 思考

触发条件：

AI 开始分析当前棋盘。

可选播放 SFX020。

建议：

默认不持续播放思考声音，只通过视觉动画表现 AI 正在思考。

### AI 弹射

AI 选中圆片并完成弹射时，按照玩家相同的规则播放：

- 圆片选中音效。
- 弹射释放音效。
- 碰撞音效。
- 得分音效。

确保 AI 和玩家遵循一致的音效反馈规则。

## 12.12 背景音乐切换逻辑

不同页面使用不同的背景音乐。

| 当前页面    | 背景音乐               |
| ----------- | ---------------------- |
| 启动页      | 不播放或使用极短启动音 |
| 主菜单      | BGM001                 |
| AI 难度选择 | BGM001                 |
| 新手教学    | BGM002 或使用较低音量  |
| 对局准备    | BGM002                 |
| 游戏对局    | BGM002                 |
| 暂停菜单    | 游戏音乐暂停或降低音量 |
| 游戏规则    | 沿用原页面音乐         |
| 结算页面    | BGM003                 |
| 设置页面    | 沿用原页面音乐         |

音乐切换要求：

1. 从主菜单进入游戏时，主菜单音乐逐渐降低。
2. 游戏音乐逐渐进入。
3. 暂停游戏时，游戏音乐逐渐降低并暂停。
4. 继续游戏时，恢复游戏音乐。
5. 结算时，停止游戏背景音乐。
6. 根据胜利、失败、平局切换对应结算音乐。
7. 返回主菜单时，重新播放主菜单音乐。

音乐切换使用平滑过渡，避免突然中断。

## 12.13 音效优先级与冲突处理

游戏中可能同时发生多个声音事件，需要统一处理。

建议优先级如下：

| 优先级 | 音效类型                 | 处理方式     |
| ------ | ------------------------ | ------------ |
| P0     | Death Finger、游戏胜负   | 优先播放     |
| P1     | 成功得分、失分、圆片夺取 | 保证清晰     |
| P2     | 强烈碰撞、回收完成       | 正常播放     |
| P3     | 中轻度碰撞、弹射         | 允许适当合并 |
| P4     | UI 点击、页面切换        | 低优先级     |

处理原则：

- 高优先级音效不能被低优先级音效覆盖。
- 重要事件发生时，适当降低背景音乐音量。
- 短时间内大量碰撞时，限制重复声音。
- 不同类型的重要音效尽量避免同时播放。
- 不允许音效突然叠加到刺耳程度。

### 音效防重复机制

例如：

一枚圆片在短时间内连续撞击多枚圆片。

需要：

- 对碰撞音效设置合理的触发间隔。
- 允许强烈碰撞覆盖较轻的碰撞表现。
- 对极短时间内发生的多次相似碰撞进行合并或筛选。
- 不影响实际碰撞和游戏规则。

注意：音效合并只影响声音表现，不影响真实的物理碰撞计算。

## 12.14 游戏音量设置

设置页面增加独立音量控制。

建议布局：

背景音乐

[ 开启 / 关闭 ]

音量调节：0% — 100%

音效

[ 开启 / 关闭 ]

音量调节：0% — 100%

震动

[ 开启 / 关闭 ]

### 默认设置

| 项目         | 默认状态           |
| ------------ | ------------------ |
| 背景音乐     | 开启               |
| 音效         | 开启               |
| 背景音乐音量 | 60%                |
| 音效音量     | 80%                |
| 震动         | 开启（设备支持时） |

以上为首版建议默认值，可以通过实际游戏测试调整。

### 音量交互

1. 玩家进入设置页面。
2. 可以独立开启或关闭背景音乐。
3. 可以独立开启或关闭音效。
4. 可以通过滑块调整背景音乐音量。
5. 可以通过滑块调整音效音量。
6. 调整后立即生效。
7. 设置自动保存在本地。
8. 下次打开游戏时恢复之前的设置。

### 特殊规则

- 背景音乐关闭，不影响操作音效。
- 音效关闭，不影响背景音乐。
- 两者同时关闭时，游戏完全静音。
- 音量设置为 0 时，对应音频不应发出声音。
- 游戏切换后台时，不允许音乐继续不受控制地播放。

## 12.15 游戏暂停与恢复的音频逻辑

玩家点击暂停按钮时：

1. 播放 SFX024。
2. 游戏背景音乐逐渐降低。
3. 游戏音乐暂停。
4. 停止非必要的环境音。
5. 不再触发新的操作音效。
6. 保留已经完成的音效播放收尾。

玩家点击继续游戏时：

1. 播放 SFX025。
2. 恢复当前游戏音乐。
3. 恢复游戏声音状态。
4. 继续当前玩家或 AI 回合。

注意：

暂停不能清除当前棋盘状态，也不能重复播放上一回合的碰撞音效。

## 12.16 系统中断与后台处理

以下情况需要考虑：

- 玩家切换其他应用。
- 玩家锁屏。
- 手机来电。
- 系统音频焦点被其他应用占用。
- 设备音量发生变化。

处理规则：

1. 游戏进入后台时，自动暂停对局。
2. 停止游戏背景音乐或按照设备音频规则处理。
3. 不再触发游戏操作音效。
4. 玩家重新进入游戏时显示暂停状态。
5. 玩家点击继续后恢复音乐。
6. 不重复播放已经完成的事件音效。

## 12.17 音效验收标准

### 基础音效

- 按钮点击有对应音效。
- 圆片选中有音效。
- 圆片释放有音效。
- AI 操作也有对应音效。
- 页面切换声音正常。

### 物理音效

- 轻微碰撞、中等碰撞、强烈碰撞具有区别。
- 不同大小圆片的碰撞表现合理。
- 连续碰撞不会产生刺耳的声音堆叠。
- 边界碰撞与圆片碰撞有所区别。

### 得分音效

- 进入目标区域有提示。
- 最终得分有确认音。
- 失分有单独反馈。
- 分数变化和声音同步。

### 特殊音效

- 回收提示正常。
- 回收完成正常。
- 圆片夺取正常。
- Death Finger 三阶段声音正常。
- 胜利、失败、平局分别使用不同音效。

### 背景音乐

- 主菜单音乐正常。
- 游戏音乐正常。
- 结算音乐正常。
- 页面切换时音乐平滑过渡。
- 暂停和恢复音乐正常。

### 设置功能

- 背景音乐可以单独关闭。
- 音效可以单独关闭。
- 两种音量可以独立调整。
- 设置可以保存到本地。
- 重新打开游戏后能够恢复设置。
